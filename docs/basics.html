7  Basics of data

7.1 Variables and observations

The following are some important data basics:

  • A variable is any characteristic whose value may change from one individual (or object) to another.

  • Data result from making observations on a single variable (called univariate data) or simultaneously on two or more variables (called multivariate data).

Note

Recall the data in Chapter 1. Each row records the survival percentage for a group of early-stage Delta smelt larvae exposed to specified light and turbidity conditions. A row is a case or observational unit; here it is a group-level record, not an individual larva. The columns are variables: light intensity (Light), turbidity (Turbidity), and survival percentage (Survival). For example, the first row records 56.8% survival for larvae exposed to light intensity of 4.5 \(\mu mol/m^2/s\) and turbidity of 2 NTUs. The experimental unit and any dependence among groups should be established from the original rearing-trial design before conducting inference.

7.2 Types of variables

Variables in a statistical study can be classified as either categorical or numerical.

  • A variable is categorical if the individual observations are categorical responses, such as labels, people’s attributes, opinions, etc.

  • A variable is numerical (or quantitative) if its corresponding observations are numerical values that are measured or counted.

Factor variables refer to the software’s representation of categorical variables. The levels of a factor are its possible categories. For example, “first-generation college student” might be coded as 1 for a first-generation student and 0 for a student who is not first-generation. A categorical variable is ordinal when its categories have a natural order, and nominal otherwise. Light and turbidity levels have a natural low-to-high order, but the examples use unordered R factors to compare categories without imposing a particular trend.

Note

The case-study data in Chapter 1 consist of three variables: Light, Turbidity, and Survival. - Survival is a numerical percentage, treated as continuous for these summaries. A numerical variable is continuous if its possible values form an interval on the number line; a proportion computed from a fixed number of larvae has a discrete set of possible values. - Light and Turbidity are both factor variables, with each having levels low, medium, and high.

ImportantR and factor variables

When data are imported (described in Appendix C) that contains factor variables, R may not automatically recognize them as such1. If the levels of the factor variables are represented by numbers, R by default, classifies these variables as numeric. If the levels are instead letters or words, R will treat them as character variables by default.

To convert a variable to a factor variable, you can use the mutate() function in the dplyr package.

7.3 .csv files

To provide a consistent approach to using R, it is assumed that any research data will be saved in the tidy format using a comma separated values (.csv) file. A .csv may be viewed with a spreadsheet program such as Microsoft Excel. It is assumed readers have used an Excel spreadsheet. If not, please view the tutorial Excel Tutorial for Beginners .

To store data in a .csv file, organize your data in an Excel worksheet, such that the first row (Row 1) contains the column (variable) names and each subsequent row contains all the necessary information for each data point. Next, save the worksheet as a .csv file type.

7.4 Tidy data

Note the format of the data presented in Chapter 1:

  • Each variable forms a column.

  • Each observation forms a row.

  • Each value must have its own cell.

When data are stored in this format, it is called tidy data (Wickham 2014).

The R code below imports two versions of the data (a tidy and non-tidy version). The R function read.csv() is described in Appendix C. The functionhead() (tail()) will print out the first (last) few rows of a data frame.

7.5 Codebooks

An important task in a data based research project is to document the structure and content of project dataset. This can be done in the form of a codebook, a file that lists at least the names of the variables, variable descriptions, and data source. Sometimes it may also provide the variables’ type (e.g., continuous, categorical) and levels of factor variables (e.g., 1 = disagree,…, 3 = agree). Writing a codebook is an important step in managing the data aspect of your research project. The codebook will serve as an important reference for the researcher and any collaborators, and there are multiple approaches for creating a codebook, with Excel being a popular choice. The next section contains a sample codebook for the case study data.
